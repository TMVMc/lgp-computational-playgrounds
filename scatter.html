Sampling positions and varying an element

The circle case is selected. The live code generates size and rotation before trying positions. Seeding, the placement loop, whole-element containment checks, other boundaries, and drawing are omitted.

// Uniform point candidates within a circle.
const angle = random() * 2 * Math.PI;
const distance = boundaryRadius * Math.sqrt(random());
const x = centerX + distance * Math.cos(angle);
const y = centerY + distance * Math.sin(angle);

const size = baseSize * (1 + (random() * 2 - 1) * scaleVariation / 100);
const rotation = (random() * 2 - 1) * rotationVariation * Math.PI / 180;
At the controls

Set scale and rotation variation to zero first. Increase each separately to see what it changes. Discs have no visible rotation, so use bars or triangles for that comparison.

How it works

A seeded random sequence supplies positions inside the chosen boundary. Each element gets a separate scale and angle. Scale varies around the base size; rotation varies in either direction from its original orientation. Elements stay inside the boundary but may overlap.

Populating a region

Start with a closed outline and one source shape. Keep the placement points separate from the geometry placed on them.

Grasshopper

  1. Use Populate 2D with a rectangular region, point count, and seed. For a circle or other outline, populate its bounding rectangle, test points with Point In Curve, and retain the inside points. Generate extra candidates if you need a particular final count.
  2. Move a copy of the source shape from its origin to every point. Use Random with a domain such as 0.5…1.5 to supply scale factors, and Scale each copy about its placement point.
  3. Generate another random list for rotation. Rotate each shape about its own center using a domain such as −π…π. Keep the seeds fixed while changing the scale and angle ranges.

Blender Geometry Nodes

  1. Fill a closed planar curve with Fill Curve, then use Distribute Points on Faces in Random mode. Density controls the expected number of points; Seed changes the arrangement.
  2. Connect a source mesh to Instance on Points. Use Random Value set to Float for a uniform scale factor on all three axes of each instance. Change Min and Max to control size variation.
  3. Use a separate Random Value for the Z angle, combine it with zero X and Y values, and convert the Euler angles to a rotation for the instance Rotation input. For a 3D surface, combine this local spin with the surface rotation.

The browser checks the whole element against the boundary. These modeling recipes initially constrain only the placement points; large instances can extend beyond the edge. Use an inset region or a further containment check when that matters. Neither recipe prevents overlaps.
