Orienting an element on the ellipse

Sampling t, the equal-distance lookup, the element loop, and drawing are omitted. a and b are the ellipse’s half-width and half-height.

const x = centerX + a * Math.cos(t);
const y = centerY + b * Math.sin(t);
const tangentAngle = Math.atan2(b * Math.cos(t), -a * Math.sin(t));
const angle = tangentAngle + extraRotation * Math.PI / 180;

// Transform a corner [u, v] from the source element.
const corner = [
  x + u * Math.cos(angle) - v * Math.sin(angle),
  y + u * Math.sin(angle) + v * Math.cos(angle)
];
At the controls

Flatten the ellipse and switch spacing modes. Equal-parameter samples cluster near its narrow ends.

How it works

Equal-distance mode uses a numerical arc-length approximation. Each element follows the local tangent; rotation adds a shared offset. The curve is an ellipse, so parameter spacing becomes uneven as its proportions change.

Following a guide curve

Sample a curve for positions and use its tangents to orient a row of modules.

Grasshopper

  1. Draw an ellipse or open guide curve. Divide Curve gives equal arc-length divisions; for the alternative mode, reparameterize the curve to 0…1 and use Evaluate Curve with a Range of parameters.
  2. Evaluate the tangent at each sample and construct a local plane. In a planar design, use the world Z direction to keep the planes consistently oriented.
  3. Use Orient to move a source module from its base plane to each target plane. Add a rotation about each plane’s normal to explore alignment.

Blender Geometry Nodes

  1. Use Resample Curve in Count mode for approximately equal-distance points. For parameter comparison on an ellipse, explicitly calculate x = a cos(θ), y = b sin(θ) from evenly spaced angles.
  2. Use Curve Tangent with Align Rotation to Vector, choosing the axis that matches the source module’s length. Connect the rotation to Instance on Points.
  3. Instance a short bar or another module on the curve points. Add a local rotation offset and adjust the count and source size independently.

On a closed curve, avoid placing both the start sample and an identical end sample. Three-dimensional curves also need a consistent normal or frame.
