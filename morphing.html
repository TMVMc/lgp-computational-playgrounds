Blending corresponding points

Source-curve sampling, correspondence rotation, and drawing the closed outline are omitted.

const t = blendPercent / 100;
const point = [
  circlePoint[0] * (1 - t) + starPoint[0] * t,
  circlePoint[1] * (1 - t) + starPoint[1] * t
];
blendedPoints.push(point);
At the controls

Move blend slowly from 0 to 100%, then rotate the correspondence to change which points are paired.

How it works

Each output point is (1 − blend) × circle point + blend × star point. Changing correspondence twists which points are paired.

Blending two outlines

Sample both curves, pair their points, and move each pair toward a shared position.

Grasshopper

  1. Create two closed planar curves with compatible orientation and deliberately aligned seams. Divide both into the same number of samples; omit the duplicate closing sample.
  2. Pair points by index and calculate P = (1 − t) × A + t × B in an Expression or Script component, with t controlled by a slider from 0 to 1.
  3. Create a closed polyline or periodic interpolated curve through the blended points. Make a planar surface from the outline, then extrude it.

Blender Geometry Nodes

  1. Resample a closed curve to a fixed count and use Index divided by that count as the sample factor. Use two Sample Curve nodes in Factor mode to sample the source curves at matching factors.
  2. Mix the two Position outputs with a Vector Mix node and a blend factor from 0 to 1. Connect the result to Set Position’s Position input on the resampled closed curve.
  3. Use Fill Curve and Extrude Mesh to study a solid profile. To explore correspondence, add an offset to one sampling factor and wrap it into 0…1.

The browser pairs curves by angle; equal-distance sampling in a modeling application creates a related, slightly different morph. Check intermediate curves for self-intersections.
