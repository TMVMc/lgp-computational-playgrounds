At the controls

Raise branch probability, then reduce the branch angle to bring the new branches closer together.

How it works

Each active tip grows one segment per step and can split into two. A fixed seed makes each parameter comparison repeatable. Growth stops at the boundary or a 4,000-segment limit.

Building a branching structure

Record each new segment while keeping track of the tips that are still growing.

Grasshopper

  1. Use a Script component to store active tips as position and direction pairs. Add inputs for step count, segment length, branch probability, angle, and seed.
  2. For each step, advance each tip and record the segment. Use a seeded random value to decide whether to replace the tip with two directions rotated by plus and minus the branch angle.
  3. Keep only the newest tips active; retain earlier segments as output geometry. Stop at a boundary and a segment limit, then Pipe the segments to study a branching network.

Blender Geometry Nodes

  1. Use points for active tips and store a direction vector on the point domain. Carry tips and accumulated segment geometry separately through a Repeat Zone.
  2. Advance each tip by direction × length. Use Random Value with point IDs and the iteration index to select branching tips; split selected tips into two new points with directions rotated by opposite angles.
  3. Add each old-to-new connection to the accumulated geometry and use only the new tips in the next iteration. Apply a fixed iteration limit, then turn the resulting curves into tubes.

The loop needs to carry two separate lists: active tips and completed segments. Completed segments stay in the output but stop growing.
