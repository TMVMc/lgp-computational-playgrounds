Computing the next row

Starting cells, generation loops, and drawing are omitted. The bit operations select one of the rule’s eight outcomes.

// Read all neighbors from the previous row, with wrapped edges.
const nextRow = cells.map((_, i) => {
  const left = cells[(i + columns - 1) % columns];
  const center = cells[i];
  const right = cells[(i + 1) % columns];
  const neighborhood = (left << 2) | (center << 1) | right;
  return (rule >> neighborhood) & 1;
});
cells = nextRow;
At the controls

Try rules 30, 90, and 110. Click the top row to change the starting cells.

How it works

This is a one-dimensional elementary cellular automaton. Each rule number encodes eight possible neighborhood outcomes; the left and right edges wrap.

Turning cells into a panel

Place a raised square wherever a cell is active. Read the rows from top to bottom to follow the pattern’s development.

Grasshopper

  1. Use a Script component with inputs for rule number, column count, row count, and a starting row of zeros and ones. Begin with one active center cell.
  2. For each new row, read left, center, and right from the previous row. Calculate neighborhood = 4 × left + 2 × center + right, then next cell = (rule shifted right by neighborhood) AND 1. Wrap neighbor indices at the edges.
  3. Output points only for active cells, with column mapped to X and generation mapped to Y. Place small boxes at those points to make a raised panel.

Blender Geometry Nodes

  1. Create a Mesh Line with one vertex per column and store a Boolean state on its points. Set only the center index to true.
  2. Inside a Repeat Zone, use Sample Index to read the previous state at wrapped indices i − 1, i, and i + 1. Build the three-bit neighborhood; compute floor(rule / 2^neighborhood) modulo 2 for the next state.
  3. Carry the current row and accumulated display geometry through the zone separately. Offset a copy by the row index, instance squares only on active points, and join each row into the display result.

Keep the previous row intact while computing the next. Updating cells one at a time would make later cells depend on results from the current row.
