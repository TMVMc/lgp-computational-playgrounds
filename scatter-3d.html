Sampling a sphere’s surface or interior

The sphere case is selected and the direction helper is expanded here. Box and cylinder sampling, element meshes, orientation, scale variation, camera controls, and rendering are omitted.

// random() returns a seeded value between 0 and 1.
const z = 2 * random() - 1;
const angle = 2 * Math.PI * random();
const ring = Math.sqrt(1 - z * z);
const normal = [ring * Math.cos(angle), ring * Math.sin(angle), z];

const radius = onSurface ? baseRadius : baseRadius * Math.cbrt(random());
const position = normal.map(component => component * radius);
Surface or volume?

Start with rods on a sphere. Set rotation variation to zero and compare surface-normal alignment with world axes. Then switch to volume placement and turn the view: the elements now occupy the interior.

How placement works

Surface points are sampled across the base form’s area; volume points are sampled throughout its interior. The seed fixes their positions. Scale and rotation use a separate random sequence, so adjusting them leaves those positions unchanged. Rotation variation applies a random turn around each local axis.

The wireframe marks the base form. Only element centers are constrained: forms can overlap and extend through the boundary. The base itself is transparent so interior elements remain visible.

Scattering in three dimensions

Grasshopper

  1. For a solid region, use Populate 3D to generate points in its bounding box, then test them with Point In Brep and retain the interior points. For a surface, generate UV samples, evaluate the surface, and obtain a normal at each point. Uniform UV samples are not generally uniform in surface area.
  2. Construct a plane at each point. Use the surface normal as its Z axis when working on a surface; use parallel world planes for the volume case. Orient a source object from its base plane to these target planes.
  3. Generate seeded Random lists for scale and rotation. Scale around each placement point and rotate about the target plane’s local axes. A rod modeled along local Z makes normal alignment easy to see.

Blender Geometry Nodes

  1. For surface placement, feed a mesh into Distribute Points on Faces. For volume placement, convert a closed mesh with Mesh to Volume, then use Distribute Points in Volume. Volume resolution affects the boundary approximation.
  2. Connect the points and a source mesh to Instance on Points. For the surface case, use the Rotation output from Distribute Points on Faces to align the source’s Z axis with the normal.
  3. Use Random Value for scale. Add Rotate Instances with Local Space enabled and random Euler angles converted to a rotation for local variation. Keep the placement seed fixed while changing the ranges.
