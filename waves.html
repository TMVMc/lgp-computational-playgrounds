Displacing one row with a sine wave

The loops that sample each row and draw the curves are omitted.

// t runs from 0 to 1 across the row.
const t = (x - 20) / 760;
const phaseOffset = phase + row * 0.3;
const y = baseline + amplitude * Math.sin(
  2 * Math.PI * frequency * t + phaseOffset
);
points.push([x, y]);
At the controls

Increase frequency from 2 to 8, then move phase to shift the waves sideways.

How it works

Each row follows y = baseline + amplitude × sin(2π × frequency × x / width + phase).

Drawing a wave curve

Displace points on a straight line with a sine function, then draw a curve through them.

Grasshopper

  1. Draw a straight line and use Divide Curve to produce evenly spaced points. Generate matching values t from 0 to 1 with Range; use the same number of steps as the curve divisions.
  2. Use an Expression: z = A × sin(2 × pi × f × t + phase). A controls height, f controls the number of cycles, and phase shifts the wave.
  3. Use Unit Z and Amplitude to create displacement vectors, then Move the division points. Interpolate the moved points to make a smooth wave curve. Pipe the curve for a tubular edge, or loft it with a second matching curve to study a strip.

Blender Geometry Nodes

  1. Create a Curve Line and add Resample Curve with enough points to describe the waves.
  2. Use Spline Parameter’s Factor as t. Multiply by frequency and 2π, add phase, apply Math set to Sine, then multiply by amplitude.
  3. Use Combine XYZ with the result in Z and connect it to Set Position’s Offset. Add Curve to Mesh with a small Curve Circle profile to make a tubular edge.

Angles are in radians. This recipe makes one wave curve; the playground repeats several rows.
