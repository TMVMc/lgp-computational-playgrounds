Offsetting a grid point with smooth noise

The seeded smooth-noise function, grid loops, and drawing helper are omitted.

const sampleX = column / density * noiseScale;
const sampleY = row / density * noiseScale;
const dx = (noise(sampleX, sampleY, seed) - 0.5) * strength * 2;
const dy = (noise(sampleX + 21, sampleY + 31, seed) - 0.5)
  * strength * 2;

dot(x + dx, y + dy, 2.6);
At the controls

Keep the seed fixed and change noise scale. Use displacement to make the underlying grid more or less visible.

How it works

Seeded values at lattice corners are interpolated with a smoothstep curve. Nearby samples stay related; scale controls the size of those relationships.

Giving a surface relief

The same noise values can control height instead of sideways displacement. Start with a grid of points and move them in Z.

Grasshopper

  1. Create a Square Grid and retain the point list. Start with height variation only, so spacing stays predictable.
  2. In a Python or C# Script component, sample a smooth seeded value-noise function at each point’s X and Y coordinates. Interpolate lattice values rather than using independent random heights. Add inputs for scale, strength, and seed.
  3. Remap the resulting values to a small positive height range. Use them to move points in Z or set the lengths of cylinders placed at the grid points.

Blender Geometry Nodes

  1. Use a Grid to supply vertices and feed Position into Noise Texture. Start with low Detail for broad variations; Scale changes their spatial frequency.
  2. Use Map Range on the Fac output to produce a chosen minimum and maximum height. Combine XYZ places this value in Z for Set Position’s Offset.
  3. Alternatively, instance a cylinder at each grid vertex and use the height field to vary its Z scale. Anchor the source cylinder at its base if you want a common underside.

The browser uses smooth value noise. Blender’s Noise Texture uses a different noise implementation, so the principle transfers but the patterns will not match exactly.
