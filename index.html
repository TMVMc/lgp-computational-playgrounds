Fields of Influence

Move the orange attractor point to change the size of nearby circles. This creates an attractor field: each circle’s size depends on its distance from the point. The circles stay in place.

Distance, falloff, and circle size

Grid generation, controls, and SVG drawing are omitted.

const distance = Math.hypot(x - attractorX, y - attractorY);
const influence = Math.max(0, 1 - distance / radius);
let weight = Math.pow(influence, falloff);
if (invert) weight = 1 - weight;

const circleRadius = 1 + (maxSize - 1) * weight;
How it works

For each point, distance d is converted to an influence between 0 and 1: w = max(0, 1 − d / radius)falloff. Inverting uses 1 − w. The influence determines the radius of each circle. The points themselves remain stationary.

Reduce the radius until only a few circles respond. Then increase it beyond the field’s edges and invert the size relationship.

Sizing a field of spheres

A sphere at each grid point gives this flat field depth. Its radius depends on the distance to the same attractor.

Grasshopper

  1. Create a rectangular point grid with Square Grid. Use Distance to measure from each grid point to one attractor point.
  2. Use an Expression to calculate w = max(0, 1 − d / R), where d is distance and R is an influence-radius slider. Raise w to a falloff power if desired.
  3. Calculate sphere radius = minimum radius + w × (maximum radius − minimum radius). Feed the grid points and these radii into Sphere.

Blender Geometry Nodes

  1. Add a Grid and use its vertices as the points for Instance on Points. Connect an Icosphere as the instance.
  2. Use Object Info in Relative transform space to get an Empty’s location. Vector Math set to Distance compares that location with Position on the grid.
  3. Use Map Range with Clamp enabled: map distance 0…influence radius to maximum…minimum scale. Connect the result to the instance Scale input. Move the Empty to shift the larger spheres.

This recipe starts with linear falloff. Add a Power operation to shape the influence as in the playground.
