At the controls

Switch between squares and hexagons. Close the gaps, then change alternate cells.

How it works

Square centers use a rectangular grid; hexagon centers use staggered columns. At zero gap, full-size modules meet edge to edge. Alternate size shrinks every other cell.

Repeating a module

The module’s shape determines the spacing of its centers. Start with edge-to-edge cells before changing their sizes.

Grasshopper

  1. Create a square lattice with two Series lists for X and Y, using Cross Reference to obtain every pair. Place equal square modules at the resulting points.
  2. For flat-top hexagons of circumradius r, use column spacing 1.5r and row spacing √3r. Shift alternate columns vertically by half a row before placing hexagons.
  3. Use the remainder after dividing row + column by 2 to select alternate cells. Scale modules around their own centers to open gaps; rotate the entire assembled pattern to preserve shared alignment.

Blender Geometry Nodes

  1. For squares, create a Grid and instance a square module on its vertices. Match vertex spacing to the module width.
  2. For hexagons, calculate column and row indices from Index on a Mesh Line. Use Combine XYZ and Set Position with x = 1.5r × column and y = √3r × (row + 0.5 × column parity).
  3. Instance a six-sided Curve Circle or mesh module with a vertex pointing along X. Use the remainder after dividing row + column by 2 for alternate scale values and Transform Geometry to rotate the complete field.

The browser draws module outlines. Scaling individual cells creates gaps rather than a continuous tessellation.
