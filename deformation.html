Setting the widths and bending a point

This shows taper followed by bend. Twist, operation-order switching, grid sampling, projection, and drawing are omitted.

// u runs from -1 at the start to +1 at the end.
const t = (u + 1) / 2;
const width = (startWidth + (endWidth - startWidth) * t) / 100;
let x = 300 * u;
let y = 75 * acrossStrip * width;
let z = 0;

// Bend angle is in radians; skip the bend when it is zero.
if (Math.abs(bendAngle) >= 1e-8) {
  const radius = 600 / bendAngle;
  const angle = x / radius;
  x = (radius - z) * Math.sin(angle);
  z = radius - (radius - z) * Math.cos(angle);
}
At the controls

Set both widths to 100% for a constant-width strip, then narrow either end. Add bend and twist and compare the two operation orders.

How it works

Start width and End width set the two ends of the strip. Width changes evenly between them; matching values give a constant-width strip. Twist rotates each cross-section around the original length axis. Bend maps length onto a circular arc. The wireframe is a projected 3D surface; changing the order changes which coordinates the next operation receives.

Transforming a strip

Work on a subdivided rectangular grid so there are enough points to describe the bends.

Grasshopper

  1. Create a rectangular point grid. Treat X as the strip’s length and Y as its width; multiply Y by a width factor interpolated between the start and end values along X.
  2. In a Script component, twist each cross-section by rotating its Y and Z coordinates about X, with angle proportional to X. Then bend about Y using a circular mapping of the X coordinate.
  3. Reverse the two transformations and compare the results. Rebuild the surface from the ordered grid points, preserving the grid’s row and column structure.

Blender Geometry Nodes

  1. Create a sufficiently subdivided Grid. Use Position and Separate XYZ; use Map Range on X to interpolate between start and end width factors, then multiply Y by that result.
  2. Use Math nodes and Combine XYZ to calculate a twist around X: y′ = y cos(a) − z sin(a), z′ = y sin(a) + z cos(a), with a proportional to X. Feed the result through Set Position.
  3. Build a second coordinate group for bending. For radius R and angle x/R, use x′ = (R − z) sin(x/R), z′ = R − (R − z) cos(x/R). Chain the groups in opposite orders to compare. Use a switch to bypass bending at zero angle.

For this bend, radius equals strip length divided by the total bend angle in radians. Check the surface for self-intersections at large bend or twist values.
