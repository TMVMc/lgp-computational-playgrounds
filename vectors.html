Combining directions and advancing one step

The field function and path loop are combined here. Seed points, tracing limits, and drawing are omitted.

const dx = centerX - x;
const dy = centerY - y;
const distance = Math.max(15, Math.hypot(dx, dy));
const vx = pull * dx / distance - swirl * dy / distance + drift;
const vy = pull * dy / distance + swirl * dx / distance;
const length = Math.hypot(vx, vy);
const direction = length < 1e-8 ? [0, 0] : [vx / length, vy / length];

x += direction[0] * 2;
y += direction[1] * 2;

How it works

Arrows combine attraction toward a center, rotation around it, and a constant rightward drift. Orange curves trace the field in small numerical steps.

Tracing paths through the field

An arrow shows the direction at one location. A path follows many such directions, recalculating after each short step.

Grasshopper

  1. Create several starting points. In a Script component, calculate a direction at each point from a weighted combination of attraction, perpendicular rotation, and constant drift.
  2. Normalize the combined vector. Advance the current point by direction × a small step length, then recompute the field at the new position. Repeat for a fixed number of steps or until a boundary is reached.
  3. Output one ordered point list per path. Build polylines or interpolated curves, then Pipe the curves to study raised wires.

Blender Geometry Nodes

  1. Begin with seed points on a Mesh Line. Subtract Position from a control Empty’s location to obtain attraction; construct a perpendicular XY vector for rotation.
  2. Combine weighted attraction, rotation, and drift vectors and normalize. A Repeat Zone advances points by this direction times a small step size, reevaluating the field at each iteration.
  3. To draw paths, retain the sampled positions and a path identifier through the loop, then use Points to Curves with that identifier and step index. Curve to Mesh can give the paths thickness.

Begin with arrows or displaced points before building paths. A small numerical step improves tracing; a fixed step limit prevents unlimited growth.
