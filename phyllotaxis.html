Positioning a point in the spiral

The point loop and dot drawing helper are omitted. Radius is normalized by point count, as in this playground.

// n is the point index; count is the total number of points.
const angle = n * divergenceDegrees * Math.PI / 180;
const radius = 210 * (spread / 100) * Math.sqrt(n / count);
const x = centerX + radius * Math.cos(angle);
const y = centerY + radius * Math.sin(angle);

dot(x, y, pointSize);
At the controls

Compare 137.5° with 135° and 144°. Look for the angles at which points line up into spokes.

How it works

Point n uses angle n × divergence and radius proportional to √n. The golden angle is approximately 137.508°. Similar spiral arrangements occur in plants.

Placing points in a spiral

Each new point turns through the same angle and moves a little farther from the center. Place discs at the points to see the arrangement.

Grasshopper

  1. Use Series to generate integer indices n from 0 to N − 1. Set angle θ = n × divergence × pi / 180 and radius r = spacing × sqrt(n) with Expressions.
  2. Calculate x = r × cos(θ) and y = r × sin(θ). Feed x, y, and z = 0 into Construct Point.
  3. Place circles or spheres at those points. Start with divergence = 137.5°, then compare 135° and 144° while leaving count and spacing fixed.

Blender Geometry Nodes

  1. Use Mesh Line to provide N vertices and Index to identify each vertex. Set Position will replace its initial coordinates.
  2. Use Math nodes to calculate θ = Index × divergence × π / 180 and r = spacing × sqrt(Index). Calculate x = r × cos(θ) and y = r × sin(θ).
  3. Combine XYZ with z = 0 and connect it to Set Position’s Position input. Use Instance on Points to place a small cylinder or sphere at every vertex.

Here spacing stays fixed, so adding points expands the arrangement. The playground normalizes radius by point count to keep the overall pattern size comparable.
